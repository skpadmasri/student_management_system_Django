# Student Management System (Django)

A full-stack web application built using **Python, Django, SQLite, HTML, and CSS** to efficiently manage student records and academic course marks with complete CRUD functionality.

## 🚀 Features
- **Create:** Add new student profiles along with course and subject marks.
- **Read:** View a structured list of all registered students and their academic records.
- **Update:** Edit and update existing student details or marks seamlessly.
- **Delete:** Remove student records from the database with confirmation.

## 🛠️ Tech Stack
- **Backend:** Python, Django
- **Database:** SQLite3
- **Frontend:** HTML5, CSS3

## ⚙️ How to Run Locally
1. Clone this repository:
 
   git clone (https://github.com/skpadmasri/student_management_system_Django.git)

2. Navigate to the project folder and run migrations:
   
  python manage.py migrate

3. Start the development server:

   python manage.py runserver

4. Open http://127.0.0.1:8000/ in your browser.
